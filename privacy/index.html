Privacy Policy – gmail-mcp

Last updated: 21 September 2026

gmail-mcp is a personal, open-source Model Context Protocol server written and operated by Charalampos Agiropoulos for his own use. It lets an AI assistant running on his own computer read, draft and send email from his own Gmail account. It is not offered as a service to anyone else.

What data is accessed

The application requests the Gmail gmail.modify OAuth scope in order to search, read, label, draft and send messages, and to download attachments, in the authorising user's own mailbox.

Where data is stored

All data stays on the user's own machine. OAuth tokens are stored in a local configuration directory with restrictive file permissions. Email content is read on demand and passed to the locally running AI assistant session; nothing is stored on any server operated by the author, and nothing is shared with, sold to, or transferred to third parties.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from Google Account permissions, or by deleting the local token file.
